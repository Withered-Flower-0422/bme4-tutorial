# Items

## Save Objects as Templates

- Select the object to save
- Select the `Assets → Items` category, click the first button on the bottom right, `Save Asset`, or directly drag the object into the `Items` panel
- Enter the template name and click the `Save` button
- After saving successfully, the object will be added to the current folder of the Items category

:::tip

Multiple objects can be saved in one template:

- Choose one of the objects as the main object
- In `Hierarchy`, drag all the objects to save onto the main object to make them its child objects (you can also organize the hierarchy yourself, but there can only be one main object)
- Select the main object and save it following the steps above
- After saving successfully, the template will save the hierarchy, relative position, rotation, scale, relative ID references and other information of all objects

:::
