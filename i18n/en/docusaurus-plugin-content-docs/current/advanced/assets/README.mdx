# Assets Panel

This page will introduce the functions of the row of buttons at the bottom of the `Assets` panel.

## Bottom Left Buttons

The bottom left buttons from left to right are:

- `Create Folder`: create a new folder under the currently selected category
- `Clear Cache`: clear all caches of the editor
- `Delete Folder`: delete the currently selected folder (the folder must be empty)
- `Mark / Unmark as Favorite`: `Mark` or `Unmark` the currently selected file as a favorite
  - Favorited custom folders will be marked yellow
  - Favorited official folders will be marked green
- `Hide / Unhide Non-favorites`: `Hide` or `Unhide` the folders that haven't been marked as favorites

## Bottom Right Buttons

The bottom right buttons from left to right are:

- `Import / New Asset`: import or create an asset of the current category into the currently selected folder
- `Delete Asset`: delete the currently selected asset
- `Import Folder`: choose a folder and import all the assets of the current category in it
- `Show in Explorer`: open the folder containing the currently selected asset in Explorer
