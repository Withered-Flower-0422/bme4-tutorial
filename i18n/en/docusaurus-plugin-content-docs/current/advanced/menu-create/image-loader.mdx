# Image Loader

## Parameter

### `Texture`

- Type: `Texture`
- Default: empty

### `Width`

- Type: `int`
- Default: `1`

### `Height`

- Type: `int`
- Default: `1`

### `Receive Lighting`

- Type: `bool`
- Default: `false`

After enabling `Receive Lighting`, the color of each pixel on the image will participate in the physical lighting calculation.
