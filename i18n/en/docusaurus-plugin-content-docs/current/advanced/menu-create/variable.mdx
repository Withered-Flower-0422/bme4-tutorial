# Variable

## Parameter

### `Variable Name`

- Type: `str`
- Default: empty

All built-in variables start with `G_`, so avoid doing so when you name a variable.

### `Variable Type`

- Type: `Literal`
- Default: `Int`

### `Variable Value`

- Type: `int | float | bool | list[float]`
- Default: `0 | 0 | false | []`

### `Persist with Save`

- Type: `bool`
- Default: `false`

## Manipulate Variables

Variables need to be [used together with scripting](../../script/executor/variable.mdx).
