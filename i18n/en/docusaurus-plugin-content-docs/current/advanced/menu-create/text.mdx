# Text

## Parameter

### `Content`

- Type: `str`
- Default: `"Text"`

### `Font Size`

- Type: `float`
- Default: `10`
- Range: `x: 0 <= x <= 50`

### `R Red`

- Type: `float`
- Default: `0.2`
- Range: `x: 0 <= x <= 1`

### `G Green`

- Type: `float`
- Default: `0.2`
- Range: `x: 0 <= x <= 1`

### `B Blue`

- Type: `float`
- Default: `0.2`
- Range: `x: 0 <= x <= 1`

### `A Alpha`

- Type: `float`
- Default: `1`
- Range: `x: 0 <= x <= 1`

It is actually `opacity`.
