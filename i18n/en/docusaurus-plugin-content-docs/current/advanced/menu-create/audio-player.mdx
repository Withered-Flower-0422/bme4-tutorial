# Audio Player

## Parameter

### `Audio File`

- Type: `Audio`
- Default: empty

### `Loop`

- Type: `bool`
- Default: `false`

### `Volume`

- Type: `float`
- Default: `1`
- Constrain: `v: 0 <= v <= 1`
