# Light

## API

### `SetLightIntensity(ID: int, intensity: float) -> None`

Set the intensity of a light.

- `intensity`: intensity

### `SetLightColor(ID: int, RGB: vec3) -> None`

Set the color of a light (its opacity is always `1`).

- `RGB`: color, each component with range `0 <= x <= 1`
