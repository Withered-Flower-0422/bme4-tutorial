# Peripheral Input

:::warning

Ballex's peripheral input logic is processed in the [image frame](../trigger.mdx#image-frame),
so when you need to use the following APIs, set the trigger mode to `Image Frame`,
otherwise the peripheral input may fail to be captured.

:::

## API

### `CheckKeyDown(key_ID: Literal) -> bool`

Check whether a keyboard key is pressed down exactly in the current image frame.

### `CheckKeyUp(key_ID: Literal) -> bool`

Check whether a keyboard key is lifted up exactly in the last image frame.

### `CheckKeyHold(key_ID: Literal) -> bool`

Check whether a keyboard key is being held in the current image frame.

- `key_ID`: key ID
- `returns`: whether the corresponding event happens

### `CheckMouseDown(button: Literal[0, 1, 2]) -> bool`

Check whether a mouse button is pressed down exactly in the current image frame.

### `CheckMouseUp(button: Literal[0, 1, 2]) -> bool`

Check whether a mouse button is lifted up exactly in the last image frame.

### `CheckMouseHold(button: Literal[0, 1, 2]) -> bool`

Check whether a mouse button is being held in the current image frame.

- `button`: mouse button
  - `0`: left mouse button
  - `1`: middle mouse button
  - `2`: right mouse button
- `returns`: whether the corresponding event happens

### `GetMousePosition() -> vec2`

Check the position of the mouse pointer in the current image frame.

- `returns`: position's component along each axis, unit is pixel, right and up are the positive directions

### `GetMouseScrollDelta() -> vec2`

Check the movement of the mouse wheel in the current image frame.

- `returns`: movement along each axis, unit is pixel, right and up are the positive directions
