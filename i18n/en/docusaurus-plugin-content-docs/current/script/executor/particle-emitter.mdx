# Particle

## API

### `PlayParticle(ID: int) -> None`

Play the particle.

### `PauseParticle(ID: int) -> None`

Pause the particle, which will resume from the paused position next time.

### `StopParticle(ID: int) -> None`

Stop the particle, which will play from the beginning next time.
