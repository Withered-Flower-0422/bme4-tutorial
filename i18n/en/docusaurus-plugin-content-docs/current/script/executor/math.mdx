# Math

## API

### `QuaternionToEuler(quaternion: quat) -> vec3`

Convert a quaternion to euler angle.

- `quaternion`: quaternion
- `returns`: euler angle

### `EulerToQuaternion(euler: vec3) -> quat`

Convert an euler angle to quaternion.

- `euler`: euler angle
- `returns`: quaternion
