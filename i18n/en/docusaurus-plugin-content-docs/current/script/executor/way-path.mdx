# Way Path

## API

### `WayPathStart(ID: int) -> bool`

Start a way path.

- `returns`: whether it starts successfully

### `WayPathStop(ID: int) -> bool`

Stop a way path.

- `returns`: whether it stops successfully

### `WayPathPause(ID: int) -> bool`

Pause a way path.

- `returns`: whether it pauses successfully

### `WayPathResume(ID: int) -> bool`

Resume a way path.

- `returns`: whether it resumes successfully
