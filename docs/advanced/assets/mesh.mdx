# 网格

如果内置的元件无法满足你的制图需求，你可以考虑自行建模。

## 导入网格

- 在三维软件建模后，将网格导出为 `.fbx` 格式
- 选中 素材 → 网格 类别，点击底部右侧的第一个按钮 导入网格
- 在弹出的对话框中选择导出的 `.fbx` 文件，点击 打开 按钮

:::tip

参见：[`起步 → 制图前准备 → 坐标系统`](../../start/preparation.mdx#坐标系统)

对于不支持导出 `.fbx` 的建模软件，可导出为其它格式的模型，导入 Blender 后再导出 `.fbx`。

已经确认可用的软件：

- [Blender](https://www.blender.org/)

:::

## 使用网格

import { TitleBadge } from "../../../src/components/Badge"

网格可直接拖至场景中使用。

### `模型网格`

- 类型：`Mesh`
- 默认值：空

该元件**显示**的网格。

### `材质`

- 类型：`list[Material.PBR]`
- 默认值：`[]`

对应关系与建模软件中的设定一致。

### `碰撞箱类型`

- 类型：`Literal`
- 默认值：`网格`

:::tip

网格模式的性能远低于另外两者，在效果满足期望的前提下，请优先选择长方体或球体模式。

:::

### `焊接碰撞箱` <TitleBadge text="物理体类型 = 静态" />

- 类型：`bool`
- 默认值：`false`

启用该功能的邻近物体会自动优化碰撞箱，尝试修正细缝、错位、轻微穿模等微小问题。

:::danger

该功能可能导致诸多违背物理的表现，包括但不限于弹跳、单轨滑落、机关穿模。除非清楚自己在做什么，请勿使用。

:::

### `偏移`

- 类型：`float` `float` `float`
- 默认值：`0` `0` `0`

### `尺寸` <TitleBadge text="碰撞箱类型 = 长方体" />

- 类型：`float` `float` `float`
- 默认值：`1` `1` `1`
- 限制：`x: x > 0` `y: y > 0` `z: z > 0`

### `圆角半径` <TitleBadge text="碰撞箱类型 = 长方体" />

- 类型：`float`
- 默认值：`0.02`
- 限制：`r: r >= 0`

### `半径` <TitleBadge text="碰撞箱类型 = 球体" />

- 类型：`float`
- 默认值：`0.5`
- 限制：`r: r > 0`

### `网格覆写` <TitleBadge text="碰撞箱类型 = 网格" />

- 类型：`Mesh`
- 默认值：空

该元件**碰撞箱**的网格。如果未设定，将与显示网格一致。

### `物理体类型`

- 类型：`Literal`
- 默认值：`静态`

各类型含义为：

- 静态：完全静止。如：地面
- 运动学刚体：静止，只能通过 [执行器](../../script/executor/physics.mdx) / [路径](../../advanced/menu-create/way-path-point.mdx) 调整位姿。如：移动路面
- 刚体：参与物理模拟，将受到各种力的影响。如：箱子
- 装饰：只显示外观，没有碰撞箱
- 碰撞箱：只有碰撞箱，在游戏中不显示。如：隐形路面

### `质量` <TitleBadge text="物理体类型 = 刚体" />

- 类型：`float`
- 默认值：`1`
- 限制：`m: 0.001 <= m <= 10000`

### `密度` <TitleBadge text="物理体类型 = 刚体" />

- 类型：`float`
- 默认值：`10`
- 限制：`ρ: 0.01 <= ρ <= 100`

### `线性阻力` <TitleBadge text="物理体类型 = 刚体" />

- 类型：`float`
- 默认值：`0.5`
- 限制：`ζ: 0.001 <= ζ <= 10000`

### `旋转阻力` <TitleBadge text="物理体类型 = 刚体" />

- 类型：`float`
- 默认值：`0.05`
- 限制：`ζ: 0.001 <= ζ <= 10000`

### `重力因数` <TitleBadge text="物理体类型 = 刚体" />

- 类型：`float`
- 默认值：`1`
- 限制：`η: -10 <= η <= 10`

1 为正常重力，0 为无重力，负数为反重力。

### `物理材质`

- 类型：`Literal`
- 默认值：`石`

影响弹力、表面摩擦系数等物理性质。

### `物理音频组`

- 类型：`Literal`
- 默认值：`石`

影响碰撞音效等游戏效果。
