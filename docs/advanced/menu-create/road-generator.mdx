# 路面生成器

- 起步章节已介绍路面生成器的 [常用基本操作](../../start/road-generator.mdx)
- 本章节仅介绍 `自定义形状` 路面生成器

## 自定义形状路面

自定义形状路面最重要的参数为 `自定义形状`，这里仅介绍 `自定义形状` 的功能，其他参数与其他路面生成器的参数功能相同。

### `自定义形状`

#### `数量`

决定有多少段路面，每组对应一段路面。

#### `顶点`

- 决定该段路面的截面由哪几个顶点组成。可自行设置顶点数量及每个顶点的坐标。
- 坐标位置为相对位置，参考面为 `以元件位置为原点的 xy 平面`
- 坐标在编辑器中可设置 `X` `Y` `Z` 坐标，**但实际上只有 `X` `Y` 有效**，代表在上述参考面内的坐标

:::tip

- 不同段的路面可以设置不同的材质

:::
