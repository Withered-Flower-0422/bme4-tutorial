# 路径 & 路点

路径需配合路点使用，用于控制元件按照指定的路线移动。

## 用法

- 创建一个路径和多个路点
- 将所有路点拖入路径层级下，使其作为路径的子元件
- 点击路径检视器中的 `获取路点` 按钮，此时可以在场景中直观观察路点所组成的路线
- 按照顺序设置好每个路点的位置、姿态、大小等属性，这些属性将影响所控制元件的位置、姿态、大小

## 路径

### `使用曲线`

- 类型：`bool`
- 默认值：`false`

勾选 `使用曲线` 后，两个路点之间的路线会使用贝塞尔曲线连接。

### `闭合路径`

- 类型：`bool`
- 默认值：`false`

勾选 `闭合路径` 后，路径会闭合，即最后一个路点会自动连接到第一个路点。

### `受控物体`

- 类型：`int[]`
- 默认值：`[]`

需要被该路径控制的元件 ID 列表。

### `循环路径`

- 类型：`bool`
- 默认值：`false`

勾选 `循环` 后，元件会按照此路径循环移动，否则，元件最终会停留在最后一个路点处。

:::danger

目前启用路径的唯一方式是 [通过脚本控制](../../script/executor/way-path.mdx)。

:::

## 路点

### `移动速度`

- 类型：`float`
- 默认值：`0`

物体从该路点运动到下一个路点的速度。

### `使用移动周期`

- 类型：`bool`
- 默认值：`false`

### `移动周期时长` <TitleBadge text="使用移动周期 = true" />

- 类型：`float`
- 默认值：`0`

物体从该路点运动到下一个路点的所需要的时长。

### `停留时间`

- 类型：`float`
- 默认值：`0`

物体在该路点停留的时间。
