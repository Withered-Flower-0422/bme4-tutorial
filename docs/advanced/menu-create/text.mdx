# 文本

## 参数

### `内容`

- 类型：`str`
- 默认值：`"Text"`

### `字号`

- 类型：`float`
- 默认值：`10`
- 范围：`x: 0 <= x <= 50`

### `R 红`

- 类型：`float`
- 默认值：`0.2`
- 范围：`x: 0 <= x <= 1`

### `G 绿`

- 类型：`float`
- 默认值：`0.2`
- 范围：`x: 0 <= x <= 1`

### `B 蓝`

- 类型：`float`
- 默认值：`0.2`
- 范围：`x: 0 <= x <= 1`

### `A 透明度`

- 类型：`float`
- 默认值：`1`
- 范围：`x: 0 <= x <= 1`

实际为 `不透明度`。
