# 变量

## 参数

### `变量名`

- 类型：`str`
- 默认值：空

所有内置变量都以 `G_` 开头，请命名时注意避开。

### `变量类型`

- 类型：`Literal`
- 默认值：`Int`

### `变量值`

- 类型：`int | float | bool | list[float]`
- 默认值：`0 | 0 | false | []`

### `跟随存档持久化`

- 类型：`bool`
- 默认值：`false`
