# 进阶

进阶板块面向已经能够熟练运用基本功能的制图师，将展示 BME4 中的高级功能。本板块中的章节不分顺序，基本互相独立，需要依赖其它功能的部分会设有引用。

阅读建议：

- 本板块将遵从技术文档的写作风格，会预设读者已经完全掌握起步板块中的所有内容，以及各章节相关的专业知识
- 你可以略读本板块，快速了解制图器的功能和潜力，也可以根据实际制图需要只选读对应的部分
- 本板块只会展现 _BME4 有哪些功能，每个参数有什么作用_，并不会讲解 _为了达成某个目标，你会需要用到哪些功能和参数_。一些常用的技法会在食谱板块讲解，而更多用法需要自己领悟
- 学会本板块的所有内容后，你将有能力制作一些复杂的元件和装饰，制作具有独特风格的地图
